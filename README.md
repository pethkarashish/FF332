# FaceFusion 3.3.2 for Pinokio

A Pinokio launcher for the official FaceFusion 3.3.2 release. The installer downloads FaceFusion from the official `facefusion/facefusion` repository at tag `3.3.2` and installs it in this Pinokio app's own environment.

This launcher is based on the official [FaceFusion Pinokio repository](https://github.com/facefusion/facefusion-pinokio), pinned to the upstream launcher revision that selected FaceFusion 3.3.2. FaceFusion itself remains the property of its authors; see [LICENSE.md](LICENSE.md).

## Install with Pinokio

1. Open Pinokio and choose **Download from URL** (in some versions, this is under **Explore**).
2. Enter `https://github.com/pethkarashish/FF332` and download the app.
3. Open the new **FaceFusion 3.3.2** app and click **Install**.
4. When installation finishes, click **Run Default**.

The FaceFusion source ZIP is not needed for this Pinokio setup; the installer fetches the exact 3.3.2 release itself.
